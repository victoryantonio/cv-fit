# CV rubric

1. Verdict hanya strong, partial, atau gap.
2. Verdict strong atau partial wajib punya kutipan CV verbatim; tanpa kutipan = gap.
3. Skor dihitung kode, bukan LLM. Ringkasan dirakit kode.
4. Saran dan cover note tidak boleh memuat angka atau nama yang tidak ada di CV.
5. Rujuk PRD.md bagian 8.8 untuk aturan lengkap.
